# Числовой мир: переход без формулы шага

**Дата:** 12 ноября 2026. Сырые числа: `out/numeric_rollout.json`.

Сеть не получает формулу `v ← 0.6v + a`. Она учит переход сама. Состояние — четыре числа `(x, y, vx, vy)`, шаг физики — вызов уже существующего `step_state` плоского мира. Латент 32 шире этих четырёх чисел. Сжатием это не называется.

Масштабы 64 и 4 — единицы входа, не правило обновления. Декодера нет. Режимы `jepa` и `direct` учились трижды, сиды 0, 1 и 2, по 3000 шагов. Шесть прогонов заняли около 4.5 минут на CPU. Чекпоинты: `out/numeric_jepa_s0.pt` … `s2` и `out/numeric_direct_s0.pt` … `s2`.

Ошибка положения — евклидово расстояние в пикселях. Ошибка скорости — евклидово расстояние в пикселях за шаг. В таблицах среднее и выборочное отклонение по одним и тем же 64 эпизодам (сиды 10000…10063). Сиды в одну цифру не усреднены. Отметки «кто лучше» нет.

## Зонд

Линейный ridge `z → (x, y, vx, vy)`, `z = E_ema(s)`, `lam = 1e-2`. Ни один сид не получил метку «схлопнулось»: все четыре R² выше 0.9.

| сид | x | y | vx | vy |
|-----|-----|-----|-----|-----|
| 0 | 0.992 | 0.988 | 0.995 | 0.995 |
| 1 | 0.989 | 0.988 | 0.990 | 0.993 |
| 2 | 0.986 | 0.989 | 0.989 | 0.994 |

У всех шести сидов среднее на шаге 20 больше среднего на шаге 1.

Отметка «короткий шаг не развален» стоит только у `direct`: среднее на шаге 1 меньше 1 px. Это проверка, что шаг не развалился. Качество перехода по ней не оценивается. Ожидание при чтении для `direct` было около 0.01 px. Измеренное среднее — 0.12…0.15 px, отклонение около 0.34, то есть среднее тянут редкие эпизоды. Вторым порогом 0.01 px не становится.

У `jepa` этой отметки нет: среднее на шаге 1 равно 1.74…2.03 px. Раскатка успехом не помечается.

## Латент, только jepa

Второй ряд не идёт через зонд. Это средний модуль разности предсказанного латента и `E_ema` истинного состояния.

|-----|-------|-------|--------|--------|
| 0 | 0.007 (0.026) | 0.044 (0.053) | 0.048 (0.046) | 0.043 (0.041) |
| 1 | 0.008 (0.026) | 0.043 (0.050) | 0.050 (0.045) | 0.043 (0.040) |
| 2 | 0.008 (0.027) | 0.040 (0.047) | 0.047 (0.044) | 0.040 (0.039) |

На шаге 1 латентная ошибка около 0.007, а пиксельная — около 2. На тех же 64 эпизодах зонд, прочитанный с истинной кодировки EMA, ошибается по положению в среднем на 1.26, 1.24 и 1.50 px (сиды 0, 1 и 2). Эта проверка не входит в JSON и порогом не является. Она отделяет чтение зонда от ошибки динамики.

## Скорость, px за шаг

На шаге 1 среднее у `jepa` 0.70, 0.80 и 0.87, у `direct` 0.40, 0.39 и 0.39. На шаге 20 у всех шести сидов среднее лежит между 2.57 и 2.98.

## Как повторить

```bash
python -m numeric.train --tag numeric
python -m numeric.rollout
python _check_numeric.py
python _check_flat.py
```

Пустой тег, `v4` и `v5-*` числовое обучение отклоняет до оптимизатора. Пиксельные чекпоинты оно не открывает.

На странице http://127.0.0.1:8765 в списке «Модель» есть пункт «числовая». Это плоский мир и чекпоинт сида 0. Остальные миры этот пункт не принимает.
