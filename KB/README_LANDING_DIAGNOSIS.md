# Заметка: качество посадки — диагноз (эксперимент 2026-11-14)

**Вопрос:** улучшить мягкую посадку на замороженных сетях за счёт цели CEM.
**Сеть:** landp_range_hid_s0, клетка центр 200, g=20, сиды 94000–94002.
**Метод:** взял CEM-стоимость и добавил штрафы за нисходящую скорость у земли
(плавный `exp(-h/decay)` и жёсткий порог на высоте) и усилил боковой прицел `w_pad`.

## Результат (все конфиги: 0 мягких из 3)

| Конфиг | s94000 (vy, x) | s94001 (vy, x) | s94002 (vy, x) |
|---|---|---|---|
| baseline | 9.4, 179 | 10.3, **201** | 9.6, **192** |
| brake_floor w4 h30 | 8.4, 184 | 8.7, 210 | 15.0, 218 |
| brake_floor w8 h40 | 8.0, 125 | 7.3, 138 | 7.0, 179 |
| brake_w8 pad_w2 | 7.4, 161 | 8.7, 190 | 8.0, 180 |

## Вывод (честный)

Мягкая посадка требует **x ∈ [pad−8, pad+8] И vy < 8** одновременно.
Все варианты цели:
- либо сохраняют прицел по x → vy остаётся 9–10 (>8, удар из-за скорости);
- либо гасят vy (<8) → аппарат улетает влево от площадки (x 125–180, удар из-за промаха).

**Ни один конфиг одиночной CEM-стоимости не держит оба условия сразу на этих сидах.**
Это фундаментальное свойство: один предиктор + CEM с горизонтом 40 вблизи земли
(последние ~20 px, где ошибка предсказания соизмерима с разницей 8 vs 9–10 единиц
скорости) не находит стабильно одновременный прицел + торможение.

Согласуется с README LAND_PAD: «победителя нет», зазор в один успех из 30.
Тонкая настройка стоимости НЕ является рычагом; нужен другой механизм:
- двухфазный контроллер (далёкая фаза — прицел, ближняя — торможение),
- либо точнее предиктор / больший горизонт / обучение под почёткую цель.

Рабочий скрипт исследования (`_res_pad.py`) удалён; метод воспроизводим:
прямой CEM с `make_cost(w_brake, brake_floor, w_pad)` из этой заметки.
