## 📋 О проекте

Демонстрация «зачем JEPA» на синтетическом мире: мяч прыгает в коробке 64×64, модель учится
в латенте (48 чисел) и планирует действия, чтобы довести мяч до зоны, названной словами.
Пиксели в поиске не участвуют — поэтому решение занимает ~70 мс на CPU вместо 8.5 с.

Два эксперимента:
1. **v0.2 «воображение»** — раскатка мира в латенте против предсказания пикселей (`imagine.py`).
2. **v0.3 «цель словами»** — фраза → зона → CEM в латенте → MPC → отчёт словами (`chat.py`, `demo_ui.py`).

Ядро — 0.94M параметров, датасета на диске нет: кадры генерируются кодом на лету.

## ⚡ Команды

```bash
pip install -r requirements.txt          # torch ставится CPU-сборкой

# обучение обеих моделей (нужны ОБЕ для честного сравнения)
python train.py --mode jepa  --steps 2500 --tag v4    # ~5.8 мин
python train.py --mode pixel --steps 2500 --tag v4    # ~15.6 мин

python probe.py --tag v4                 # латент → слова, ~20 с
python chat.py                           # чат: «положи мяч в верхний левый угол»
python plan.py --goal "в центр" --cost mixed          # один эпизод + gif
python eval.py --tag v4 --cost latent --seeds 10      # 90 эпизодов, ~1 мин
python demo_ui.py                        # страница на http://127.0.0.1:8765
```

## 🔬 Правила экспериментов

- **Меняешь мир (`GRAVITY`, `IMPULSE`, `VEL_DECAY`, `SIGMA`) — переобучай ОБЕ модели**
  (`jepa` и `pixel`), иначе сравнение нечестное: baseline посчитан на другом мире
- **Метрики — только из скриптов** (`eval.py`, `probe.py`), не «на глаз» по гифке
- **Теорию не выдавать за замер.** Формулировки «должно работать» без прогона в отчёт не идут
- **Проверяй, что предиктор вообще смотрит на действие**: сравни
  `MSE(pred(a₁), pred(a₂))` с ошибкой предсказания. Если эффект меньше ошибки — предиктор
  действие игнорирует (так и было в v0.3, лечится в 3 приёма, см. `KB/README_PLAN.md`)
- **Перед выводом «модель работает»** — прогон ≥ 30 эпизодов: мир хаотичен из-за отскоков,
  на 2–5 эпизодах успех гуляет на ±20 п.п.
- **Прогоны не идентичны между запусками** (порядок суммирования во float + хаос отскоков).
  Разницу режимов меньше ~8 п.п. считать шумом, а не результатом

## ⚠️ Грабли (подробно — в `KB/README_PLAN.md`)

1. **Сдвиг целей в лоссе на кадр** — лосс рос, хотя модель «училась». Цели: `x0..x5`, действия `a0..a4`, 3 шага раскатки
2. **Scale race латента** — норма² доходила до 478, MSE рос при падении относительной ошибки.
   Лечится `unit_norm` (единичная сфера, стиль BYOL/VICReg)
3. **Предиктор игнорировал действие** — эффект 0.0004 против ошибки 0.002. Лечится: действие как
   геометрический вектор + residual-предсказание + затухание скорости
4. **Probe на одном латенте не видит скорость** — физически её там нет, вход должен быть парой `[z_prev | z_cur]`
5. **Разбор фраз** — в `find_zone` побеждает самое длинное совпадение («верхний правый» ≠ «верхний центр»)
6. **Дефолт `--tag`** — после смены архитектуры старые чекпоинты не грузятся; актуальный тег `v4`
