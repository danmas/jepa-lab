# numeric-land-skill-split

Разделение по тяжести без передачи на последних метрах: при `g ≥ 15` эпизод ведёт правило до
касания, при `g ≤ 8` — труба. Сетка этапа 4 плюс блок повтора. Обучения нет.

- `proposal.md` — зачем и что меняется.
- `design.md` — порог `15`, тождество `557`/`150`, шесть условий.
- `tasks.md` — чек-лист. В этом изменении он ещё не выполнен.
- `specs/numeric-land-skill-split/spec.md` — требования и сценарии.

Код пишется после `openspec validate --strict` и явной просьбы выполнить задачи.
