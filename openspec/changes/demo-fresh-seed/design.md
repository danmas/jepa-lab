## Context

`World(seed)` и CEM с `manual_seed(seed)` делают прогон функцией сида. Страница шлёт число из поля «Стартовый сид», оно по умолчанию 1 и само не меняется.

Повтор по явному сиду нужен командной строке и проверкам. Его убирать нельзя.

## Goals / Non-Goals

**Goals:**

- Два подряд запуска с одной фразой на странице получают разные сиды.
- На экране видно, какой сид только что использован.

**Non-Goals:**

- Случайность внутри одного сида.
- Смена сидирования в `plan.py`, `numeric/plan.py`, eval и chat.
- Кнопка «повторить этот сид».

## Decisions

- Новый сид выбирает страница, целое от 0 до 999999999, не равное сиду прошлого запуска. Сервер использует присланное число, как и раньше.
- Поле только для показа: подпись «Сид прогона», правка вручную не принимается.
- В JSON ответа есть `seed`. Строка отчёта на странице его показывает.
- Пиксельный и числовой прогоны оба идут через одну функцию `run`, поэтому оба получают новый сид.

## Risks / Trade-offs

- [Два запуска теоретически могут вытянуть одно число] → повторный жребий, пока число не отличается от прошлого. Совпадение с ещё более ранним прогоном не запрещается.
- [Нельзя закрепить понравившийся ролик кнопкой] → число сида видно. Повторить его можно командой `plan.py --seed`, не страницей.
