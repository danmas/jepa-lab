# numeric-land-skill-assemble

Этап 4 иерархической посадки: тот же полный контур, что в этапе 3, на сетке шире зачётной —
крайние тяжести и дальние площадки. Обучения нет.

- `proposal.md` — зачем нужен этап и что меняется.
- `design.md` — сетка `600`, четыре линии (знакомая часть, сумма, клетки, абляция), замер времени.
- `tasks.md` — чек-лист. В этом изменении он ещё не выполнен.
- `specs/numeric-land-skill-assemble/spec.md` — требования и сценарии.

Код пишется после `openspec validate --strict` и явной просьбы выполнить задачи.
