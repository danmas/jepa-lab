## Why

Страница умеет вести мяч пиксельной моделью и числовой JEPA в пикселях за кадр. Модель с явным `dt` на ней не видна: у неё другой интегратор и скорость в пикселях в секунду. Пока пункта нет, сравнить шаг `1/60` и `1/15` глазами нельзя.

## What Changes

- На странице третий пункт модели: `numeric-dt`. По умолчанию по-прежнему пиксельная. Запрос без поля `model` остаётся пиксельным. Пункты `pixel` и `numeric` не меняют поведения.
- Прогон читает только `out/numeric_dtB_jepa_s0.pt`: рука B, вариант с каналом `dt`, сид обучения 0. Остальные одиннадцать чекпоинтов, вариант без `dt` и прямой предиктор на страницу не выходят. Пиксельные миры для этого пункта не принимаются. Ползунки холмов прогон не двигают.
- Физика прогона — интегратор из изменения `numeric-dt`, не `step_state`. Старт: тот же ящик, скорость `20…60` px/с. Длительность шага на странице — одно из трёх: `1/60`, `1/30`, `1/15`. Нет поля — `1/30`. Чужое значение отклоняется.
- План как у числовой страницы: CEM `128×8`, горизонт 10 шагов выбранного `dt`, в мир уходит первое действие, потолок 20 шагов. Стоимость — квадрат положения из замороженного зонда до центра зоны. Кадр на экране — для глаз. В сеть идут пять чисел `(x, y, vx, vy, dt)`.
- Подпись и отчёт называют руку B, сид 0, зонд и выбранный `dt`. Для `1/60` и `1/15` отчёт говорит «экстраполяция». Прогон не называется замером. Жёлтая стрелка — направление толчка, не путь за шаг.
- JSON раскатки `out/numeric_dt_rollout.json` и остальные одиннадцать чекпоинтов это изменение не производит. Заметки `KB/README_NUMERIC.md` и оба отчёта не переписываются.

## Capabilities

### New Capabilities

- `numeric-dt-demo`: пункт `numeric-dt` на странице проверки, физика с явным `dt`, один чекпоинт руки B.

### Modified Capabilities

Нет. Пиксельный и прежний числовой прогоны остаются как были.

## Impact

- `demo_ui.py` получает третье значение модели и выбор `dt`.
- Каталог `numeric_dt/`: шаг интегратора, обучение варианта с `dt` и план для страницы. Корневые `data.py` и `step_state` не меняются.
- Файл `out/numeric_dtB_jepa_s0.pt`. Если его нет, страница отказывает и называет команду обучения.
- Проверка шага — `python _check_numeric_dt.py`. `python _check_flat.py` остаётся зелёным.
