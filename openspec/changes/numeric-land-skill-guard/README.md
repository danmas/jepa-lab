# numeric-land-skill-guard

Страховка этапа 4: там, где труба вне своего домена, действие берёт правило. Сетка `600`
этапа 4 плюс блок повтора на свежих сидах. Обучения нет.

- `proposal.md` — зачем страховка и что меняется.
- `design.md` — ворота `g ≥ 15` и `|x − pad_x| ≥ 100`, три столбца, пять условий, блок повтора.
- `tasks.md` — чек-лист. В этом изменении он ещё не выполнен.
- `specs/numeric-land-skill-guard/spec.md` — требования и сценарии.

Код пишется после `openspec validate --strict` и явной просьбы выполнить задачи.
