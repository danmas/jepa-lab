# numeric-land-skill-brake

Торможение заложено в цель трубы: желаемая боковая скорость наведения умножается на `0.6`, поэтому
ориентир больше не просит предельную скорость, и труба не перелетает площадку. Сетка этапа 4 плюс
блок повтора. Обучения нет.

- `proposal.md` — зачем и что меняется.
- `design.md` — замер коэффициента, восемь условий, границы изменения.
- `tasks.md` — чек-лист. В этом изменении он ещё не выполнен.
- `specs/numeric-land-skill-brake/spec.md` — требования и сценарии.

Код пишется после `openspec validate --strict` и явной просьбы выполнить задачи.
