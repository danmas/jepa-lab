## Why

Этап 1 не закрыт: `landk_pad_s0` дал `4` мягких из `162` при линии `114`. Правило с наведением
на тех же стартах даёт `156/162`, то есть задача посильна и мир с сеткой не виноваты.

Замер стоимости на горизонте `3` (729 планов, шесть состояний сетки) показал, где провал:

- разброс стоимости между лучшим и худшим планом `0.00060…0.00083` при ошибке предиктора
  `0.00676`, это `0.06…0.12` от ошибки;
- знаковая проверка на `18` состояниях (`g` `2/8/15`, `h` `32/64/128`, `dx = ±6`): текущая
  стоимость при `dx > 0` предпочитает план с первым действием **вправо** в `9` случаях из `9`,
  а при `dx < 0` — влево в `9` из `9`. То есть она тянет не туда систематически;
- отсюда снос по `x` в замкнутом контуре: `+3.2…+98.1 px`, медиана `0.096 px/шаг`, всегда вправо.

Проверенная альтернатива — труба: цель на каждом из трёх шагов берётся с правильной траектории,
а не с точки на земле. Она даёт верный знак в `18` случаях из `18` и разброс стоимости
`0.00140…0.00211`, это в `2–4` раза выше текущей. Мягких (`vy < 8`) у навыка сейчас `63` из
`162`: вертикаль уже почти держится, ломает площадку именно боковой знак.

## What Changes

- Стоимость поиска: вместо латента одной терминальной точки на земле — латент правильного
  состояния на каждом из трёх шагов (труба).
- Трубу строит правило с наведением, и только как источник цели. Действие по-прежнему выбирает
  латентный поиск: все `729` последовательностей, горизонт `3`, без CEM.
- Обучения нет. Прогон идёт на уже готовых `out/landk_pad_s0.pt` и `out/landk_pad_s1.pt`.
  Новые чекпоинты не пишутся, прежние не перезаписываются.
- Физика, площадка `8`, порог `vy < 8`, бак `10`, `NAV_TOL`, `HOVER_CAP`, `expert_hover.py`,
  демо-страницы и кодировщик не меняются.
- Линия `114` из `162`, сетка `162`, горизонт `3`, число планов `729` после чисел не двигаются.

## Capabilities

### New Capabilities

- `numeric-land-skill-tube`: стоимость поиска по трубе правильных состояний. Правило даёт цель,
  действие выбирает только латентный предиктор.

### Modified Capabilities

Нет. Спека `numeric-land-skill-land` остаётся как запись прогона `4/162` и не переписывается.

## Impact

- Новые модули: стоимость и труба, прогон сетки, контроль до прогона. Контроль —
  `python _check_numeric_land_skill_tube.py`.

  Правок в нём нет.

- Новых зависимостей нет.
