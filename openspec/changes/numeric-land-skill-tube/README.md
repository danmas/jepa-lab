# numeric-land-skill-tube

Пересмотр этапа 1: стоимость поиска строится на трубе правильных состояний, а не на одной
точке на земле. Обучения нет, прогон на уже готовых `landk_pad_s0`.

- `proposal.md` — зачем и что меняется.
- `design.md` — труба, веса, обрезка на касании, линия `114`.
- `tasks.md` — чек-лист. В этом изменении он ещё не выполнен.
- `specs/numeric-land-skill-tube/spec.md` — требования и сценарии.

Код пишется после `openspec validate --strict` и явной просьбы выполнить задачи.
